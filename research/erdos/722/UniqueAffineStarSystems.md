# Asymmetric Steiner quadruple systems with one affine star

For every $d\ge6$, put $n=2^{d+2}$ and $b=\binom n3/4$. There is a family of Steiner quadruple systems on $4n$ points whose members have binary incidence rank $4n-(d+3)$ and trivial full point automorphism group. Each is nonisomorphic to every member of the notebook’s preceding Latin-coset family. At 1,024 points the new family alone contains at least
\[
13824^{679318}\,13608^{255}\,4^{690624}
\]
distinct classes of rank 1,015. The comparison uses every permutation of the 1,024 points. [Existence and count](Erdos722UniqueAffineStarCount.lean) · [disjointness and rank](Erdos722DisjointAffineStarClasses.lean) · [preceding family](https://github.com/vincentkoc/solved-conjectures/pull/450)

## How the blocks identify a point

Take the affine quadruple system on $n$ binary vectors as the base. Each fibre has four points, labelled by $\mathbb F_2^2$. Call a transversal graph **affine** if its assignments are closed under coordinatewise ternary addition. Every permutation of four symbols is an affine permutation of $\mathbb F_2^2$, so changing the origin or labels in any single fibre preserves this property. For a normalized ternary quasigroup, closure applied to the three coordinate axes forces its table to be $q(a,b,c)=a+b+c$. Undoing normalization gives exactly 864 affine and 54,432 nonlinear labelled Latin cubes. [Intrinsic operation](Erdos722IntrinsicLatinAffinity.lean) · [enumeration](Erdos722NonlinearLatinCubes.lean) · [graph equivalence](Erdos722AffineTransversalGraphs.lean)

Keep affine transversal graphs on every base block through zero. The private coefficient system from the previous construction detects all $4^n$ possible fibre translations. Select at most $2n$ of its block equations that still detect every translation. Each time an undetected translation survives, adding a coordinate on which it is nonzero at least halves the remaining kernel. Protect those blocks as well. Through each other point choose a marker outside the protected blocks and require its cube to be nonlinear. A base point occurs in $\binom{n-1}{2}/3$ blocks and a pair in $(n-2)/2$, leaving more than $2n$ candidates away from zero whenever $n\ge64$. Markers can coincide. [Kernel selection](Erdos722SparseCoordinateDetection.lean) · [incidence bounds](Erdos722AffineStarBlockLayout.lean) · [layout existence](Erdos722SparseMarkedLayouts.lean)

Zero is now the unique base point incident only with affine transversal graphs. The binary parity checks recover the partition into four-point fibres from the block set. Consequently every unrestricted point isomorphism respects this unique base point. The pair matchings there are all identities, which forces a common linear part for the fibre permutations. The rigid matching then leaves only fibre translations. In the preceding coset family every point outside the reserved coset has an affine star, so at least two points do. This excludes overlap for the two full families. ## Exact count and scope

Let $e$ be the number of protected blocks, $m$ the number of distinct markers and $f=b-e-m$ the number of unrestricted sites. The protected offsets form a group of order $4^e$. The translations embed in it with order $4^n$. Fixing one representative of each quotient class leaves $4^{e-n}$ offset choices. A point isomorphism between two chosen representatives forces equality of the offsets and vanishing of the translation. The block set then recovers every local cube. The exact number for this fixed layout is
\[
55296^f\,54432^m\,4^{e-n}=13824^f\,13608^m\,4^{b-n}.
\]
The layout uses at most $\binom{n-1}{2}/3+2n$ protected blocks and $n-1$ markers. The uniform lower bound counts all guaranteed sites, charging the smaller local count on up to $n-1$ of them. [Offset quotient](Erdos722ExteriorOffsetQuotient.lean) · [completion rules](Erdos722UniqueAffineStarSystems.lean) · [parameter recovery](Erdos722AffineStarRigidity.lean)

Zinoviev and Zinoviev’s Construction II supplies the four-point-fibre framework with independent transversal codes, and their work counts non-full-rank systems. Krotov and Potapov give the order-four quasigroup enumeration. Mendelsohn’s theorem already realizes arbitrary finite automorphism groups. The contribution here is the intrinsic affine-star invariant, the choice of a small set of detecting equations, and the resulting exact family count and disjointness proof. Historical priority for this particular invariant and count is unestablished.
