Codex assisted with the proofs. Each file prints its theorem’s axioms. The notes link the original question, prior work and the proof.

| [Both Lucas–Fibonacci diagonals](arxiv/2211.10788/DiagonalUnion.md) | A natural number occurs on either diagonal iff `x² − 5y² = ±44` for some natural `x`. The lower diagonal uses `x ≡ −7y (mod 22)`. The only common value is 5. | Infinitude of prime values on either diagonal remains open. |
| [Square Lucas–Fibonacci values](arxiv/2211.10788/SquareValues.md) | The upper diagonal has exactly three squares, 1, 4 and 9. The lower has just 81. Together these give all four solutions of Cohn’s two norm-44 quartics. | Infinitude of prime values remains open. |

## Replay

Use Python 3.9 or newer and a Formal Conjectures checkout at `f606af160664c5a10952e9a957b100a1cd45bbeb` with its pinned Lean 4.33.1 dependencies. Set `FC` to the path of that checkout. Run the following from this repository’s root. The individual proof notes also use `$notebook` to locate their Lean files from `$FC`.

```bash
export notebook="$PWD/research"
runner="$PWD/scripts/replay-research"
(cd "${FC:?set FC to the Formal Conjectures checkout}" && lake env python3 "$runner")
```

The runner discovers every `.lean` file under `research/`, resolves its imports with Lean, and compiles notebook dependencies first. Use a unique module filename for each proof. Each file must print its theorem’s axioms. The runner checks the reports against `propext`, `Classical.choice` and `Quot.sound`, then runs `leanchecker` on one notebook module at a time so each process releases its memory before the next starts. Compiled notebook files are temporary.

The [theta Fourier replay](arxiv/theta-sum/FOURIER.md#replay) first compiles its diagonal-module dependency.
