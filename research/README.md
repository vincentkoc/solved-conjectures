# DeepMind proof notebook

These Lean files contain a proof of the positive Green 54 declaration and results on other problems in [Formal Conjectures](https://github.com/google-deepmind/formal-conjectures/tree/f606af160664c5a10952e9a957b100a1cd45bbeb). Codex assisted with the proofs. Each file prints its theorem’s axioms. The notes link the original question, prior work and the proof.

| [Green 28 · arithmetic of uniform sums](green/GREEN-28-ARITHMETIC.md) | A uniform independent sum forces both marginals’ point probabilities to be algebraic and to generate the same real subfield. Rational probability ratios on either side force both marginals to be uniform. | The case of two nonuniform marginals with irrational mass ratios remains open. |
| [Green 28 · finite quadratic tests](green/GREEN-28-FINITE-TEST.md) | With at most `k` sum outcomes, it suffices to test two probability vectors on `[0,5^(k+1)]`. | [Green 28 · four atoms per marginal](green/GREEN-28-FOUR-ATOMS.md) | If each independent integer law has at most four atoms and their sum is uniform, both marginals are uniform.
