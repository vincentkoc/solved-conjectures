# Archived Lean files

These are exact copies of Lean files we submitted, taken from the pull-request
head commits recorded in [`index.json`](../index.json). They are here so the
catalogue is self-contained.

They are not a Lake package and will not build on their own. The canonical,
kernel-checked versions live in the linked pull requests in the host projects
(primarily [open-math-agents](https://github.com/GuillaumeBAUD-coder/open-math-agents)
and [formal-conjectures](https://github.com/google-deepmind/formal-conjectures)).

Closed or superseded submissions may still be kept when the Lean is ours, so
the work is not lost. Duplicates that were never meant to land (for example
formal-conjectures #8406) are listed in the index but not copied.
